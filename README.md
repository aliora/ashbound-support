# Ashbound privacy & support

Public, buildless English privacy policy and support page for Ashbound (also known as Dash Peak).

- Publisher: Polat Kargılı
- Privacy and player support: polatkargili@gmail.com
- Privacy URL: https://aliora.github.io/ashbound-support/
- Support URL: https://aliora.github.io/ashbound-support/#support

## Hosting

GitHub Pages publishes the root directory of `main`. No dependencies, JavaScript, external fonts, tracking code or build step are required. `.nojekyll` keeps the site static.

## Editing

Update `index.html` and the effective date when the policy changes. Keep disclosures aligned with the actual game and advertising SDKs. Update the public game name when the store name is finalized. App Store age ratings and advertising-content settings do not by themselves determine a child-directed audience.

Preview with `python3 -m http.server 8765` from this directory. Check mobile and desktop layouts, keyboard navigation, anchor links and the email action before publishing changes.

GitHub Pages logs visitor IP addresses for security; see the policy's hosting disclosure. The public repository contains only this site's files.
